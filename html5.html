1. Intro to Full Stack Development (FSD)

Meaning: Building both the client side (front-end) and server side (back-end) of web applications.
Definition: Full Stack Development encompasses the entire software layer stack including UI/UX design, client logic, backend server API design, data storage, database management, and cloud deployment.
Purpose: Enables software engineers to independently architect, build, test, and maintain end-to-end web applications.
Example: Developing Amazon: HTML/CSS/JS for UI, Node/Python for order processing APIs, and MySQL/MongoDB for storing products and user accounts.
// Client Side (Front-End) <--- APIs ---> Server Side (Back-End) <---> Database

2. Intro to HTML (HyperText Markup Language)

Meaning: The foundational standard markup language used to structure web documents.
Definition: HTML uses markup tags to tell web browsers how to format text, display images, embed videos, and hyperlink pages together across the internet.
Purpose: Serves as the skeletal framework of every single website on the Internet.
Example: Web browser reading plain markup text and converting it into visual buttons, text blocks, and clickable hyperlinks.
<h1>Welcome to Full Stack Web Development!</h1>
Task: Write a paragraph in your notebook explaining why HTML is classified as a markup language rather than a programming language.

3. Basic HTML5 Document Structure

Meaning: The essential boilerplate layout mandatory for valid modern web documents.
Definition: A standardized hierarchy comprising `<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>` tags ensuring proper rendering by browsers.
Purpose: Tells web browsers the document standard, character encoding, title metadata, and body display area.
Example: Standard starter template used when creating any `.html` file.
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>My First Page</title> </head> <body> <h1>Hello World!</h1> </body> </html>

4. HTML Elements & Tags

Meaning: The core building blocks of HTML web pages.
Definition: An HTML element consists of a starting tag (`<tag>`), content in between, and a closing tag (`</tag>`). Self-closing tags do not require a separate closing tag.
Purpose: Instructs the browser engine how to interpret and format specific pieces of content.
Example: Heading element `<p>Sample Text</p>` vs Void/Self-closing element `<img src="pic.jpg" />`.
<p>This is an HTML Element containing content.</p>
Task: List 5 container elements and 3 void/self-closing elements side-by-side in your notebook.

5. Heading Tags (<h1> to <h6>)

Meaning: Structural heading tags defining page topic hierarchy.
Definition: Six levels of section headings from `<h1>` (most important/largest) down to `<h6>` (least important/smallest).
Purpose: Establishes document structure for screen readers, web accessibility, and Search Engine Optimization (SEO).
Example: `<h1>` for primary title, `<h2>` for major sections, `<h3>` for sub-topics.
<h1>Main Title (H1)</h1> <h2>Section Title (H2)</h2> <h3>Sub-Section (H3)</h3>
Task: Create a mini blog post structure using all six heading levels sequentially.

6. Paragraph Tag (<p>)

Meaning: Container element for grouping text into distinct paragraph blocks.
Definition: A block-level tag that automatically adds top and bottom margins around text content.
Purpose: Organizes body copy into clean, readable text paragraphs.
Example: Grouping blog article body copy into separate readable blocks.
<p>Full stack developer training empowers students to build end-to-end applications.</p>
Task: Write two separate `<p>` tags and inspect their default spacing in Chrome DevTools.

7. Bold (<b> & <strong>) Tags

Meaning: Tags used to emphasize text visually and semantically.
Definition: `<b>` makes text bold visually without extra importance. `<strong>` bolds text and marks it semantically as urgent/important.
Purpose: Draws reader attention to key terms, warnings, or highlighted phrases.
Example: `<strong>Warning:</strong> Password is required.`
<p>Please read the <strong>Important Notice</strong> carefully.</p>
Task: Compare `<b>` and `<strong>` in screen reader output mode.

8. Underline & Italic Tags (<u>, <i>, <em>)

Meaning: Inline styling tags for emphasis, terms, or underline decorations.
Definition: `<u>` adds an underline, `<i>` italicizes text visually, while `<em>` indicates semantic emphasis.
Purpose: Highlight technical vocabulary, foreign phrases, or titles of works.
Example: `<em>Latin:</em> <i>Carpe Diem</i> - <u>Seize the Day</u>.`
<p>Learn <em>HTML5</em> and <u>CSS3</u> thoroughly.</p>
Task: Create a single sentence using `<b>`, `<i>`, `<u>`, and `<em>` tags together.

9. Line Break Tag (<br>)

Meaning: Forces an inline line break without creating a new paragraph block.
Definition: A void self-closing tag (`<br>`) that forces content following it to start on the next line immediately.
Purpose: Formats physical addresses, poems, or short line breaks where paragraph margin spacing is undesired.
Example: Writing multi-line street address blocks inside a single container tag.
<p>Somesh Hadve Training Hub<br>Sector 15, Tech City<br>Mumbai, India</p>
Task: Format a 4-line poem using a single `<p>` tag with `<br>` tags.

10. Horizontal Rule Tag (<hr>)

Meaning: Creates a thematic divider line separating content blocks.
Definition: A void/self-closing tag (`<hr>`) that renders a visual horizontal line across its parent container width.
Purpose: Visually splits distinct topics, chapter breaks, or sections within a single HTML page.
Example: Placing a line separator between a blog post and its comment section.
<h2>Section 1: Introduction</h2> <p>Content here...</p> <hr> <h2>Section 2: Details</h2>
Task: Add an `<hr>` separator between two heading blocks and inspect its rendering.

📅 Lecture 02 | Module 02: Links, Media & Semantic HTML Day 2

11. Hyperlinks & Anchor Tag (<a>)

Meaning: Navigational elements linking web pages or external resources.
Definition: The `<a>` tag creates clickable links using the `href` (hypertext reference) attribute to specify the URL destination.
Purpose: Connects pages internally or externally and links resources like email (`mailto:`) or downloadable files.
Example: Clicking a link to navigate from home page to contact page or opening in new tab (`target="_blank"`).
<a href="https://google.com" target="_blank" rel="noopener">Visit Google</a> <a href="mailto:contact@somesh.com">Email Us</a>
Task: Build a mini navigation menu linking to 3 different external websites opening in a new tab.

12. Images & Media (<img>, <video>, <audio>, <iframe>)

Meaning: Multimedia elements for embedding images, audio tracks, video streams, and external frames.
Definition: Standard HTML5 tags designed to render graphic formats (`<img>`), audio files (`<audio>`), video streams (`<video>`), and external web pages (`<iframe>`).
Purpose: Enhances UI with visual, acoustic, and embedded interactive content.
Example: Showing user avatars, playing tutorial videos, streaming audio clips, or embedding YouTube/Google Maps frames.
<img src="logo.png" alt="Company Logo" width="200" /> <audio controls src="audio.mp3"></audio> <video width="320" height="240" controls> <source src="movie.mp4" type="video/mp4"> </video> <iframe src="https://maps.google.com" width="400" height="300"></iframe>
Task: Create a multimedia gallery embedding an image with alt text, an audio track with controls, and a YouTube video iframe.

13. HTML Lists (<ul>, <ol>, <li>)

Meaning: Elements for presenting items in sequential or non-sequential bullet points.
Definition: `<ul>` creates bulleted unordered lists, `<ol>` creates numbered ordered lists, `<li>` represents individual list items, and defines description lists.
Purpose: Organizes structured content such as navigation menus, feature bullet lists, and step-by-step instructions.
Example: Navigation menus (`<ul><li>Home</li></ul>`) or numbered steps (`<ol><li>Step 1</li></ol>`).
<ul> <li>HTML5</li> <li>CSS3</li> </ul> <ol type="1"> <li>Front-End</li> <li>Back-End</li> </ol>

Definition: `header`, `nav`, `main`, `section`, `article`, and `footer` tags replace non-semantic generic `div` tags to describe content roles.
Purpose: Improves SEO (Search Engine Optimization (google, yahoo, bing)), code maintainability, and accessibility compliance for screen readers.

📅 Lecture 03 | Module 03: Tables, CSS Types & Attributes Day 3

15. HTML Tables (<table>, <tr>, <th>, <td>)

Meaning: Grid layout markup for presenting tabular data in rows and columns.
Definition: `<table>` `<tr>` (table row), `<th>` (header cell), and `<td>` (data cell) along with `colspan`/`rowspan` attributes.
Purpose: Displays structured dataset information such as schedules, pricing plans, and financial statements.
Example: Rendering a 3x3 student report card table with column headings.
<table border="1"> <tr> <th>Subject</th> <th>Marks</th> </tr> <tr> <td>HTML5</td> <td>95</td> </tr> </table>
Task: Create a student grade sheet table incorporating `colspan="2"` for merged heading cells.

16. Types of CSS (Inline, Internal, External)

Meaning: Three techniques used to attach CSS styling rules to HTML elements.
Definition: **Inline** uses `style=""` attribute inside elements. **Internal** uses `<style>` block in `<head>`. **External** uses `<link rel="stylesheet">` to connect external `.css` files.
Purpose: Provides flexibility for quick inline tweaks, page-specific styles, or clean project-wide style management.
Example: Using External CSS for master application themes to maintain separation of concerns.
<!-- Inline --> <h1 style="color: red;">Text</h1> <!-- Internal --> <style> h1 { color: red; } </style> <!-- External --> <link rel="stylesheet" href="style.css">
Task: Apply Inline, Internal, and External CSS to three separate paragraphs and verify specificity priorities.

17. Class & ID Attributes

Meaning: Global attributes used to target and identify HTML elements.
Definition: `class` assigns non-unique identifiers shared by multiple elements. `id` assigns a unique, single-use identifier to an element on a page.
Purpose: Enables targeted CSS styling and precise JavaScript DOM selection/manipulation.
Example: `.btn` class applied to 10 buttons; `#main-header` id applied to only 1 primary header.
<button class="btn primary-btn">Submit</button> <div id="hero-section">Welcome</div>
Task: Write HTML markup with 3 elements sharing 1 class name and 1 element with a unique ID attribute.

📅 Lecture 04 | Module 04: SEO, Meta Tags, Entities & Forms Day 4

18. Meta Tags & SEO (Search Engine Optimization) Basics

Meaning: Metadata tags located inside `<head>` providing data about the HTML document to search engines and browsers.
Definition: Invisible elements specifying character sets, viewport scaling for mobile responsiveness, search descriptions, and keywords.
Purpose: Drives Search Engine Optimization (SEO), indexing, social media preview cards, and mobile display scaling.
Example: `meta charset="UTF-8"`, `meta name="viewport"`, `meta name="description"`.
<meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <meta name="description" content="Somesh Hadve Full Stack Developer Notes">
Task: Add essential mobile viewport and meta description tags to your HTML head section.

19. Entities & Symbols

Meaning: Text escape codes used to display reserved HTML characters and special symbols safely.
Definition: Special string sequences starting with `&` and ending with `;` representing characters like `<` (`&lt;`), `>` (`&gt;`), copyright (`&copy;`), or non-breaking spaces (`&nbsp;`).
Purpose: Prevents browsers from misinterpreting raw HTML characters like `<` or `>` as markup code.
Example: Displaying code snippets on screen: `&lt;div&gt;` prints as `
`.
<p>Copyright &copy; 2025 Somesh Hadve. 5 &lt; 10 &amp; 20 &gt; 15</p>
Task: Write a paragraph using `&copy;`, `&trade;`, `&reg;`, `&nbsp;`, and `&amp;` entities.

20. HTML Forms (<form>, <input>, <select>, <textarea>)

Meaning: Interactive components used to collect user inputs and send datasets to a web server.
Definition: `<form>` container holding input elements like text, password, email, radio, checkbox, file, date, dropdown `<select>`, `<textarea>`, and `<button>`.
Purpose: Enables user interaction, authentication, search queries, feedback, and data submissions.
Example: Login forms, contact forms, user registration forms, and search bars.
<form action="/submit" method="POST"> <label for="email">Email:</label> <input type="email" id="email" name="user_email" required> <button type="submit">Submit</button> </form>
