📅 Lecture 01 | Module 01: Intro, Grid System & Typography Day 1

1. Intro to Bootstrap & Versions

Meaning: The world's most popular free front-end framework for fast, responsive web development.
Definition: A pre-written collection of CSS and JS files that provide standard UI components and a responsive grid system. Current modern version is Bootstrap 5 (dropped jQuery dependency).
Purpose: Drastically reduces custom CSS writing time and ensures websites are mobile-friendly out of the box.
Example: Creating a fully styled responsive button by just adding `class="btn btn-primary"` instead of writing 10 lines of CSS.
<!-- No custom CSS needed! --> <button class="btn btn-success">Click Me</button>
Task: Explain in your notebook why Bootstrap 5 is faster than Bootstrap 4 (Hint: Vanilla JS vs jQuery).

2. Adding Bootstrap (CDN vs Download)

Meaning: Methods to integrate the Bootstrap framework into your HTML project.
Definition: **CDN (Content Delivery Network):** Linking to Bootstrap files hosted online. **Download:** Saving the CSS/JS files locally in your project folder.
Purpose: CDN provides faster load times (cached by browsers). Download allows offline development without internet.
Example: Pasting the CDN link inside the `<head>` of your HTML file.
<!-- CSS CDN --> <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet"> <!-- JS CDN (For Modals, Dropdowns) --> <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
Task: Create a new `index.html` file and successfully link the Bootstrap 5 CSS and JS CDNs.

3. Bootstrap Grid System (.container, .row, .col)

Meaning: A 12-column responsive layout system built on CSS Flexbox.
Definition: Layouts must follow a strict hierarchy: A `.container` holds `.row`s, and `.row`s hold `.col`umns. The total column span in a row must equal 12.
Purpose: Aligns content perfectly and handles wrapping on smaller mobile screens automatically.
Example: Creating two equal 50% width columns using `.col-6`.
<div class="container"> <div class="row"> <div class="col-6">Left Side (50%)</div> <div class="col-6">Right Side (50%)</div> </div> </div>
Task: Build a 3-column layout where each column takes up 4 spaces (`.col-4`).

4. Typography, Text Colors & BG Colors

Meaning: Pre-built utility classes to quickly style text sizes and container colors.
Definition: Typography: `fs-1` (largest) to `fs-6` (smallest). Colors use semantic names: `primary` (blue), `success` (green), `danger` (red), `warning` (yellow), `dark` (black), `light` (grey). Prefix with `text-` or `bg-`.
Purpose: Colors convey meaning automatically (e.g., red for errors, green for success) without custom CSS.
Example: A large red error message on a dark background.
<p class="fs-2 text-danger bg-dark p-3">Error: Invalid Password!</p>
Task: Create a `.container` with a `bg-primary` background and `text-light` white text.

📅 Lecture 02 | Module 02: Components & Responsive Utilities Day 2

5. Components: Buttons & Badges

Meaning: Pre-styled clickable action elements and small status indicators.
Definition: Add `.btn` + `.btn-[color]` to any `<a>` or `<button>`. Badges use `.badge` + `.text-bg-[color]` for small inline labels.
Purpose: standardizes UI interactions and highlights notification counts.
Example: A submit button with a "New" notification badge inside it.
<button class="btn btn-primary"> Messages <span class="badge text-bg-danger">4</span> </button>
Task: Create an outline button using `.btn-outline-success` and add a badge to it.

6. Components: Cards

Meaning: Flexible, boxed content containers with headers, footers, and images.
Definition: Uses `.card` for the wrapper, `.card-img-top` for images, and `.card-body` for padded text content.
Purpose: The industry standard layout for displaying products, blog posts, or user profiles.
Example: A standard e-commerce product display box.
<div class="card" style="width: 18rem;"> <img src="pic.jpg" class="card-img-top" alt="..."> <div class="card-body"> <h5 class="card-title">Product Name</h5> <a href="#" class="btn btn-primary">Buy Now</a> </div> </div>
Task: Build a 3-column grid (`.col-4`) and place a `.card` inside each column.

7. Components: Alerts

Meaning: Colored feedback messages for user actions.
Definition: Uses `.alert` and semantic color classes like `.alert-success` or `.alert-danger`. Can be dismissible using JS attributes.
Purpose: Informs users about successful form submissions or login errors.
Example: A green success message after a user registers.
<div class="alert alert-success" role="alert"> Your account has been created successfully! </div>
Task: Create a red `.alert-danger` warning users about an invalid password.

8. Components: Navbar

Meaning: A responsive navigation header that collapses into a hamburger menu on mobile.
Definition: Built with `.navbar`, `.navbar-brand` (logo), `.navbar-toggler` (mobile button), and `.navbar-collapse` (the menu links).
Purpose: Provides consistent, mobile-friendly site navigation out of the box.
Example: A dark themed top navigation bar.
<nav class="navbar navbar-expand-lg navbar-dark bg-dark"> <div class="container"> <a class="navbar-brand" href="#">MySite</a> </div> </nav>
Task: Copy the standard Navbar component from the Bootstrap Docs and paste it into your page.

9. Utilities: Show/Hide & Breakpoints (d-none, d-md-block)

Meaning: Classes used to instantly hide or show elements based on screen size without custom media queries.
Definition: `d-none` hides an element. The `md`, `lg`, `xl` infixes apply rules at specific breakpoints. `d-md-block` means "display as block on medium screens and up".
Purpose: Perfect for hiding heavy desktop sidebars when viewing on mobile phones.
Example: Hiding a promotional banner on small screens but showing it on laptops.
<!-- Hidden on mobile, visible on medium+ --> <div class="d-none d-md-block bg-info">Desktop Banner</div>
Task: Create a div that says "Mobile View" (visible on mobile only) and one that says "Desktop View".

10. Utilities: Responsive Text & Alignment

Meaning: Adjusting text alignment dynamically based on the device width.
Definition: Classes like `text-center`, `text-start` (left), and `text-end` (right). Can be combined with breakpoints: `text-center text-md-start`.
Purpose: Keeps text centered on narrow phone screens for readability, but left-aligned on wide desktop monitors.
Example: A heading that centers itself only on mobile devices.
<h2 class="text-center text-md-start">Responsive Title</h2>
Task: Write a paragraph that aligns to the right on desktop, but centers on mobile.

📅 Lecture 03 | Module 03: Forms, JS Components & UI Polish Day 3

11. Forms & Input Styling

Meaning: Standardized classes that make raw HTML forms look professional and uniform.
Definition: Apply `.form-control` to text inputs/textareas, `.form-select` to dropdowns, and `.form-label` to labels.
Purpose: Automatically sets 100% width, adds soft borders, and provides a glowing blue focus ring on click.
Example: A clean email input field.
<div class="mb-3"> <label class="form-label">Email address</label> <input type="email" class="form-control" placeholder="name@example.com"> </div>
Task: Build a Login form with Email, Password (`.form-control`), and a Submit button.

12. JS Components: Modals

Meaning: A popup dialog box overlaid on the main screen that requires user interaction.
Definition: Uses `data-bs-toggle="modal"` on a button to trigger a hidden `.modal` container via Bootstrap's built-in JavaScript.
Purpose: Used for "Confirm Delete" warnings, image lightboxes, or quick login forms without leaving the page.
Example: A button opening a popup window.
<button data-bs-toggle="modal" data-bs-target="#myModal">Open</button> <!-- Modal HTML structure goes here -->
Task: Copy the standard Modal from the Bootstrap Docs and trigger it using a green success button.

13. JS Components: Dropdowns & Collapse (Accordion)

Meaning: Interactive elements that toggle content visibility on click.
Definition: **Dropdowns** open a menu list (`.dropdown-menu`). **Collapse / Accordions** slide open vertical panels of content (`data-bs-toggle="collapse"`).
Purpose: Saves screen space by hiding secondary menus and long FAQ answers until clicked.
Example: An FAQ Accordion hiding answers.
<button data-bs-toggle="collapse" data-bs-target="#faq1">Show Answer</button> <div id="faq1" class="collapse">This is the hidden answer.</div>
Task: Build a 2-item Accordion for a Frequently Asked Questions (FAQ) section.

14. JS Components: Carousel

Meaning: A slideshow component for cycling through images or text.
Definition: Built with `.carousel`, `.carousel-inner` holding `.carousel-item`s. Includes next/prev controls and indicators.
Purpose: Creates highly interactive image galleries and hero banner sliders on landing pages.
Example: A rotating slider of 3 promotional images.
<div class="carousel slide" data-bs-ride="carousel"> <div class="carousel-inner"> <div class="carousel-item active"><img src="img1.jpg"></div> </div> </div>
Task: Implement a Carousel with 3 dummy images and enable auto-sliding.

15. Borders, Rounded Corners & Font Awesome

Meaning: Final polish utilities and external icon integration.
Definition: `.border`, `.border-danger` add colored strokes. `.rounded`, `.rounded-circle` handle border-radius. **Font Awesome** is an external icon CDN used alongside Bootstrap.
Purpose: Rounds out sharp edges, outlines sections, and replaces text with visual icons (like search magnifying glasses).
Example: A circular profile picture with a thick blue border and a FontAwesome user icon.
<img src="avatar.jpg" class="rounded-circle border border-primary border-3"> <i class="fa-solid fa-user"></i>
