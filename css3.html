📅 Lecture 01 | Module 01: Basics, Selectors, Pseudo Elements & Units Day 1

1. Intro to CSS (Cascading Style Sheets)

Meaning: A styling language used to describe the presentation and aesthetic appearance of HTML elements.
Definition: CSS controls element layouts, colors, fonts, device responsiveness, animations, and visual positioning across web pages.
Purpose: Separates page content structure (HTML) from visual presentation and design styling (CSS).
Example: Transforming a plain black text list into a vibrant, multi-column navigation menu with hover animations.
body { background-color: #f4f4f4; font-family: Arial, sans-serif; }
Task: Create an external stylesheet `style.css` and set the body background color to soft light blue.

2. Universal, Class & ID Selectors (*, . , #)

Meaning: Target methods used to select HTML elements for styling.
Definition: `*` targets all elements (often used to reset margins). `.className` targets elements with a specific class. `#idName` targets a single unique element.
Purpose: Provides precision targeting to style elements globally, as a group, or individually.
Example: Using an ID for a navbar and a Class for buttons.
* { margin: 0; } .btn { color: white; background: blue; } #main-nav { height: 60px; }
Task: Write CSS rules using one Universal, one Class, and one ID selector.

3. Combinators (Descendant, Child)

Meaning: Target rules based on the relationship between HTML elements.
Definition: Descendant (Space ` `) targets all nested elements. Child (`>`) targets only direct immediate children.
Purpose: Scopes styles specifically without needing extra class names.
Example: Styling links only inside the footer vs links directly inside a list item.
div p { color: gray; } /* Descendant */ ul > li { list-style: none; } /* Direct Child */
Task: Style only anchor tags nested immediately inside `<nav>` elements.

4. Pseudo-classes & Pseudo-elements

Meaning: Keywords that target specific states or specific parts of an element.
Definition: `:hover`, `:focus`, and `:nth-child` target user interactions or positions. `::before` and `::after` insert visual content via CSS.
Purpose: Adds dynamic interactions (like button hover color) and decorative elements without altering HTML.
Example: Changing background on hover, or adding quote marks before text.
button:hover { background-color: #94d2bd; } h1::before { content: "📌 "; }
Task: Make a link turn orange when hovered, and add an arrow symbol after it using `::after`.

5. Colors & Units (Hex, RGBA, px, %, em)

Meaning: Formats defining visual hues and spatial measurements.
Definition: Colors use Names (`red`), Hex (`#ff0000`), or RGBA (`rgba(255,0,0,0.5)` for transparency). Units use `px` (absolute), `%` (relative to parent), or `em`/`rem` (relative to font size).
Purpose: Ensures accurate branding colors and scalable, accessible sizing.
Example: Setting a semi-transparent background with a percentage width.
div { background: rgba(0, 0, 0, 0.8); width: 50%; font-size: 1.5rem; }
Task: Create a container 80% wide with a Hex background color and 16px text.

📅 Lecture 02 | Module 02: Box Model, Typography & Backgrounds Day 2

6. CSS Box Model (Margin, Border, Padding, Content)

Meaning: The foundational conceptual box wrapping every rendered HTML element.
Definition: Composed of four layers ordered from inside out: **Content**, **Padding** (inner space), **Border**, and **Margin** (outer space).
Purpose: Dictates spatial layout, element dimensions, and gaps between UI components.
Example: Adding internal padding around text and outer margin spacing between adjacent cards.
.box { width: 300px; padding: 20px; border: 5px solid #005f73; margin: 15px; }
Task: Draw and label the CSS Box Model layers in your notebook. Note where `box-sizing: border-box` takes effect.

7. Typography & Text Styling

Meaning: CSS rules governing text appearance, alignment, and spacing.
Definition: Properties include `font-family`, `text-align`, `line-height`, `letter-spacing`, and `text-transform`.
Purpose: Enhances content readability, visual hierarchy, and brand typography.
Example: Centering heading titles and capitalizing all letters.
h1 { text-align: center; text-transform: uppercase; letter-spacing: 2px; line-height: 1.4; }
Task: Import a Google Font via `@import` and apply it to a paragraph with 1.6 line-height.

8. Backgrounds & Gradients

Meaning: Styling the visual layer behind HTML element content.
Definition: Use `background-color`, `background-image`, `background-size`, or `linear-gradient()`.
Purpose: Adds visual flair, hero banner wallpapers, or branded UI textures.
Example: Setting a full-width background image that covers the container without repeating.
.hero { background: linear-gradient(135deg, #005f73, #0a9396); background-size: cover; }
Task: Create a div that acts as a square card. Apply a 2-color linear gradient background to it.

📅 Lecture 03 | Module 03: Borders, Display, Position & Z-Index Day 3

9. Borders & Border Radius

Meaning: Properties for drawing outer stroke lines and rounding container corners.
Definition: `border` sets width, style (solid/dashed), and color. `border-radius` rounds element corners.
Purpose: Separates elements visually and creates pill-shaped buttons or circular avatars.
Example: `border-radius: 50%` turns a perfect square container into a circle.
.avatar { border: 2px solid #333; border-radius: 50%; }
Task: Make a rectangular button and apply `border-radius: 20px` to make it pill-shaped.

10. Display & Visibility (Block, Inline, none)

Meaning: Determines how an element flows in the layout and if it is visible.
Definition: `block` takes full width; `inline` takes only content width; `inline-block` allows width/height adjustments while flowing inline. `display: none` removes from document; `visibility: hidden` hides but keeps space.
Purpose: Controls structural alignment of UI elements and toggles hiding.
Example: Turning horizontal list links into block items.
a { display: inline-block; width: 100px; } .hidden { display: none; }
Task: Place three `<div>` blocks side-by-side using `display: inline-block`.

11. Position (static, relative, absolute, fixed, sticky) & Z-Index

Meaning: Overriding default document flow to pin or move elements precisely.
Definition: `relative` acts as an anchor. `absolute` pins inside a relative parent. `fixed` pins to the screen. `sticky` toggles on scroll. `z-index` manages 3D front-to-back overlapping.
Purpose: Builds sticky navbars, floating notification badges, and modals.
Example: Pinning a navbar to the top of the screen.
.navbar { position: sticky; top: 0; z-index: 100; } .badge { position: absolute; top: -5px; right: -5px; }
Task: Create a "Back to Top" button fixed to the bottom-right corner of the window.

📅 Lecture 04 | Module 04: Flexbox & CSS Grid Day 4

12. Flexbox (Containers, Direction, Alignment)

Meaning: A 1-Dimensional layout system for aligning items in rows or columns.
Definition: Initiated with `display: flex`. Uses `justify-content` (main axis), `align-items` (cross axis), `flex-direction`, and `gap`.
Purpose: Perfect centering, space distribution, and navbar layouts.
Example: Centering content perfectly dead-center inside a container.
.container { display: flex; justify-content: center; align-items: center; gap: 15px; }
Task: Use Flexbox to align a logo to the far left and navigation links to the far right inside a header.

13. CSS Grid (Rows, Columns, Gap, Areas)

Meaning: A 2-Dimensional layout system managing columns and rows simultaneously.
Definition: Initiated with `display: grid`. Define layouts using `grid-template-columns` (using `fr` units) and `grid-template-areas`.
Purpose: Simplifies complex full-page layouts and multi-card image galleries.
Example: Defining a 3-column layout grid of equal width.
.grid { display: grid; grid-template-columns: 1fr 1fr 1fr; gap: 20px; }
Task: Create a simple 2x2 grid featuring four colored squares.

📅 Lecture 05 | Module 05: Responsive Design, Transitions & Animations Day 5

14. Responsive Design & Media Queries

Meaning: Techniques allowing website layouts to adapt to mobile, tablet, and desktop screens.
Definition: `@media` queries target specific viewport breakpoints to change CSS logic dynamically.
Purpose: Prevents horizontal scrolling and UI breaking on small smartphones.
Example: Changing a 3-column grid to a 1-column grid on screens smaller than 768px.
@media screen and (max-width: 768px) { .grid { grid-template-columns: 1fr; } }
Task: Write a media query that hides a sidebar sidebar class completely on mobile devices.

15. Transitions & Transforms

Meaning: Properties controlling smooth state changes and spatial manipulations.
Definition: `transition` dictates the timing/speed of CSS changes. `transform` scales, rotates, or moves elements.
Purpose: Adds smooth interactivity when hovering over buttons or cards.
Example: A button smoothly enlarging when hovered.
.btn { transition: transform 0.3s ease; } .btn:hover { transform: scale(1.1); }
Task: Make an image scale up slightly and rotate 5 degrees when the user hovers over it.

16. CSS Keyframe Animations

Meaning: Multi-stage complex CSS animations running automatically.
Definition: Defined via `@keyframes` blocks and triggered by the `animation` property.
Purpose: Animates loading spinners and attention-grabbing UI loops.
Example: Creating a continually spinning loader icon.
@keyframes spin { 100% { transform: rotate(360deg); } } .loader { animation: spin 1s linear infinite; }
Task: Build a pulsing button animation using keyframes spanning 0% to 100%.
