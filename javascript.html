📅 Lecture 01 | Module 01: Intro, Variables & Data Types Day 1

1. Intro to JavaScript & Types of JS

Meaning: A dynamic, high-level programming language primarily used for web interactivity.
Definition: JS adds logic and interactivity to static HTML/CSS. It can be written internally inside `<script>` tags or externally in `.js` files.
Purpose: Used to manipulate the DOM, validate forms, handle events, and fetch data.
Example: Clicking a button to show a popup alert on the screen.
<!-- Internal --> <script> alert("Hello!"); </script> <!-- External --> <script src="app.js"></script>
Task: Link an external `app.js` file to your HTML and print "Connected" in the console.

2. Variables & Data Types

Meaning: Containers for storing data values.
Definition: JS uses `let`, `const`, and `var`. Data Types include String, Int/Float (Number), Boolean (true/false), Null (empty), and Undefined (unassigned).
Purpose: Allows programs to store user inputs and perform calculations.
Example: Storing a username as a String and age as a Number.
let name = "Somesh"; // String let age = 25; // Number (Int) let isTrainer = true; // Boolean let data = null; // Null
Task: Create variables representing your name, age, and a boolean indicating if you like coding.

3. The typeof Operator

Meaning: A command to check the data type of a given value or variable.
Definition: Returns a string indicating the type of the unevaluated operand.
Purpose: Crucial for debugging and validating data before performing operations.
Example: Checking if a user input is a number or text.
console.log(typeof "Hello"); // Outputs: "string" console.log(typeof 42); // Outputs: "number"
Task: Use console.log and typeof to check what type a `null` value returns in JS (Hint: It's an object!).

📅 Lecture 02 | Module 02: Operators, Arrays, Objects & Functions Day 2

4. Operators

Meaning: Symbols used to perform arithmetic, logical, or comparison operations on variables.
Definition: Includes Arithmetic (`+`, `-`, `*`, `/`), Comparison (`==`, `===`, `>`, `<`), and Logical (`&&`, `||`, `!`).
Purpose: Builds mathematical logic and condition-checking inside programs.
Example: Checking if age is greater than 18.
let sum = 10 + 5; let isAdult = age >= 18 && hasID === true;
Task: Write a script that checks if `10 === "10"` and explain the result.

5. Arrays & Methods (push, pop, shift, unshift)

Meaning: A single variable used to store a list of multiple values.
Definition: Ordered lists defined by `[]`. Methods alter the list: `push()` adds to end, `pop()` removes from end, `unshift()` adds to start, `shift()` removes from start.
Purpose: Manages collections of data like a list of users or shopping cart items.
Example: Adding a new student to a class list array.
let fruits = ["Apple", "Banana"]; fruits.push("Mango"); // Adds to end fruits.shift(); // Removes "Apple" from start
Task: Create an array of 3 colors. Add a color to the start and remove the last color.

6. Iteration Methods (map, filter, reduce, forEach)

Meaning: Built-in array functions to loop over and manipulate data efficiently.
Definition: `forEach` loops without returning, `map` creates a new array, `filter` creates an array of passing conditions, `reduce` boils down to a single value.
Purpose: Replaces traditional loops with clean, readable data transformation logic.
Example: Filtering an array of numbers to keep only even ones.
let nums = [1, 2, 3, 4]; let evens = nums.filter(n => n % 2 === 0); nums.forEach(n => console.log(n));
Task: Use `.map()` to multiply every number in an array by 2.

7. Objects & Functions

Meaning: Objects store key-value pairs; Functions store reusable blocks of code.
Definition: Objects use `{}` with properties. Functions are defined with the `function` keyword or as arrow functions `() => {}`.
Purpose: Structures complex data (Objects) and prevents repeating logic (Functions).
Example: A user object passed into a greeting function.
let user = { name: "Somesh", role: "Trainer" }; function greet(u) { return "Hello " + u.name; }
Task: Create an object of a car (brand, model). Write a function that prints its details.

📅 Lecture 03 | Module 03: Events, Conditions & Loops Day 3

8. Events & Conditions

Meaning: Capturing user actions (clicks, typing) and executing logic based on decisions.
Definition: Events like `onclick` trigger JS. Conditions (`if`, `else if`, `switch`) control the flow of execution.
Purpose: Makes websites interactive and smart based on user choices.
Example: Changing background color ONLY if a button is clicked.
function checkAge(age) { if (age >= 18) { alert("Welcome"); } else { alert("Too young"); } } <button onclick="checkAge(20)">Enter</button>
Task: Write a switch statement that takes a day number (1-7) and logs the day name.

9. Loops (for, while)

Meaning: Structures to run a block of code repeatedly.
Definition: `for` runs a specific number of times; `while` runs as long as a condition remains true.
Purpose: Prevents manual code repetition when generating lists or parsing data.
Example: Printing numbers 1 to 5 automatically.
for (let i = 1; i <= 5; i++) { console.log("Number: " + i); }
Task: Write a while loop that prints numbers from 10 down to 1.

📅 Lecture 04 | Module 04: DOM, Async JS & Debugging Day 4

10. DOM Manipulation

Meaning: Interacting directly with HTML elements via JavaScript.
Definition: Document Object Model (DOM) methods like `getElementById` or `querySelector` target elements to change their text, styles, or classes.
Purpose: Dynamically updating the page without reloading.
Example: Changing a heading text when a form is submitted.
let title = document.querySelector("#main-title"); title.innerText = "Updated by JS!"; title.style.color = "red";
Task: Create an empty `<div id="box">` and use JS to add a paragraph inside it.

11. Asynchronous JS & Error Handling

Meaning: Handling tasks that take time (like timers or data fetching) without freezing the UI.
Definition: Uses Callbacks, Promises, `setTimeout`, and `async/await`. Errors are caught using `try...catch` blocks.
Purpose: Ensures the website remains usable while waiting for server data.
Example: Showing a loader, fetching data, then hiding the loader safely.
try { setTimeout(() => { console.log("Runs after 2 seconds"); }, 2000); } catch (error) { console.error("Bug found:", error); }
Task: Write a script that uses `setTimeout` to trigger an alert 3 seconds after page load.

📅 Lecture 05 | Module 05: Storage, Closures & This Day 5

12. Browser Storage (LocalStorage)

Meaning: Saving data inside the user's browser that survives page reloads.
Definition: `localStorage.setItem()` and `getItem()` store strings permanently until cleared.
Purpose: Remembers user preferences, light/dark mode, or cart items.
Example: Saving a user's name so they stay logged in.
localStorage.setItem("username", "Somesh"); let user = localStorage.getItem("username");
Task: Build a button that saves "Dark Mode = Active" in localStorage.

13. Closures, Hoisting & `this`

Meaning: Core advanced behavioral concepts in JS execution.
Definition: **Closure:** An inner function remembering the variables of its outer function. **Hoisting:** JS moving declarations to the top before execution. **this:** Refers to the object currently executing the code.
Purpose: Essential for mastering JS interviews and scope control.
Example: Using `this` inside an object to access its own properties.
let person = { name: "Alex", speak: function() { console.log(this.name); } }; person.speak();
Task: Write a simple closure where an outer function returns an inner function.

📅 Lecture 06 | Module 06: API & JSON Handling Day 6

14. API Integration (GET/POST & JSON)

Meaning: Connecting your front-end JS to external backend servers to send or receive live data.
Definition: An Application Programming Interface (API) is accessed using the `fetch()` method. Data is transmitted as JSON strings.
Purpose: Populates websites with real-world data like weather, stocks, or users.
Example: Fetching a list of fake users from JSONPlaceholder API.
fetch("https://jsonplaceholder.typicode.com/users") .then(response => response.json()) .then(data => console.log(data));
Task: Fetch data from a free weather API and `console.log()` the current temperature.
