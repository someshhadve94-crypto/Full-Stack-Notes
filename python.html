Meaning: The process of examining raw data to draw conclusions and support decision making.
Definition: Data Analytics involves collecting, cleaning, analyzing and visualizing data using tools like Python, Excel, SQL and Power BI.
Purpose: Helps businesses find trends, predict sales, understand customers and make smart decisions.
Example: An e-commerce store analyzing which products sell most in Diwali season using Python charts.

2. Intro to Python

Meaning: A high-level, easy to read, general purpose programming language.
Definition: Python was created by Guido van Rossum. It is interpreted, dynamically typed and supports web dev, DA, AI, automation and backend development.
Purpose: Used as backend language in Full Stack Python development and as main language for automation and data handling.
Example: Instagram, YouTube backend and Django websites are built using Python.
print("Hello Python")

3. Install Python

Meaning: Setting up Python interpreter and code editor on your computer.
Definition: Download from python.org, tick Add to PATH during install, verify with python --version in terminal, then install VS Code.
Purpose: Prepares your system to write, run and debug Python programs locally.
Example: Running python --version shows Python 3.12.0 confirming successful install.
python --version pip --version
Task: Install Python, verify version in CMD, and run your first print program in VS Code.

4. Python Syntax

Meaning: The set of rules that define how Python code must be written.
Definition: Python uses indentation (4 spaces) instead of brackets to define blocks. Every statement ends with newline, no semicolon needed.
Purpose: Keeps code clean, readable and forces proper structure.
Example: An if block must be indented, otherwise Python throws IndentationError.
if 5 > 2: print("Five is greater")

5. Comments in Python

Meaning: Non-executable lines used to explain code for humans.
Definition: Single line comment uses #. Multi-line comment uses triple quotes ''' or """.
Purpose: Improves readability, helps teamwork and debugging.
Example: Adding a note above complex logic explaining what it does.
# This is single line comment '''This is multi line comment'''
Task: Add comments to your last 3 programs explaining each line.

6. Variables in Python

Meaning: Named containers used to store data values.
Definition: Created with assignment operator =. No need to declare type. Name must start with letter or underscore.
Purpose: Stores user data, calculation results and reusable values.
Example: Storing student name and marks.
name = "Somesh" age = 25 print(name, age)
Task: Create variables for your name, city and age and print them in one line.

7. Data Types (String, Int, Float, Boolean, Null)

Meaning: Classification of data that tells Python what kind of value is stored.
Definition: String (text in quotes), Int (whole numbers), Float (decimals), Boolean (True/False), NoneType (None = null / empty).
Purpose: Decides what operations are allowed on a value.
Example: You can add Int + Int but not Int + String without casting.
a = "Hello" # String b = 10 # Int c = 10.5 # Float d = True # Boolean e = None # Null print(type(b))

8. Operators in Python

Meaning: Special symbols to perform operations on values.
Definition: Arithmetic (+ - * / // % **), Comparison (== != > <), Logical (and or not), Assignment (= += -=).
Purpose: Builds calculations, comparisons and decision logic.
Example: Checking login condition with comparison + logical operator.
x = 10 + 5 # 15 print(10 == 10 and 5 > 2) # True

9. User Inputs in Python

Meaning: Taking data from keyboard during program run.
Definition: input() function always returns data as String. Shows prompt message inside brackets.
Purpose: Makes programs interactive like forms and billing systems.
Example: Asking user name and printing welcome message.
name = input("Enter your name: ") print("Hello", name)

10. Casting (Type Conversion)

Meaning: Converting one data type into another.
Definition: int() converts to integer, float() to decimal, str() to string. Needed because input() always gives string.
Purpose: Allows mathematical calculations on user input.
Example: Converting age input string to int for age + 1 calculation.
age = input("Enter age: ") age = int(age) print(age + 1)

11. Functions in Python

Meaning: Reusable block of code that runs only when called.
Definition: Defined with def keyword, can take parameters and return value with return statement.
Purpose: Avoids repetition, organizes logic like billing or validation.
Example: A greet function reused for many users.
def greet(name): return "Hello " + name print(greet("Somesh"))

📅 Lecture 03 | Module 03: Scope, Conditions & Nested IF Day 3

12. Scope in Python

Meaning: The region where a variable can be accessed.
Definition: Local scope = inside function. Global scope = outside all functions. Use global keyword to modify global variable inside function.
Purpose: Prevents name clash and controls data access.
Example: A variable defined inside function cannot be used outside.
x = 100 # global def test(): y = 10 # local print(x + y) test()
Task: Create global and local variables with same name and observe which value prints inside function.

13. Conditions (if, elif, else)

Meaning: Decision making statements that run code only if condition is True.
Definition: if checks first condition, elif checks next, else runs when all fail.
Purpose: Controls flow like pass/fail, login check, discount logic.
Example: Grading system based on marks.
marks = 75 if marks >= 90: print("A Grade") elif marks >= 60: print("B Grade") else: print("Fail")
Task: Take age as input and print Child, Teen, Adult or Senior using if-elif-else.

14. Nested IF

Meaning: An if statement placed inside another if statement.
Definition: Outer condition is checked first, inner condition is checked only if outer is True.
Purpose: Handles multi-level checks like login + OTP verification.
Example: Check username first, then check password inside.
user = "admin" pwd = "1234" if user == "admin": if pwd == "1234": print("Login Success") else: print("Wrong Password")
Task: Build ATM logic: if pin correct, then check balance > amount for withdrawal.

📅 Lecture 04 | Module 04: Modules, Dates, Math & Loops Day 4

15. Modules in Python

Meaning: Ready-made Python files containing useful functions.
Definition: Import with import module_name and use as module_name.function(). You can also create your own .py module file.
Purpose: Reuses code, avoids rewriting complex logic.
Example: Importing math module to use sqrt function.
import math print(math.sqrt(16))
Task: Import math module and use ceil, floor and pow functions.

16. Dates in Python

Meaning: Handling current date, time and formatting.
Definition: datetime module provides date, datetime, now(), year, month, day, strftime() for formatting.
Purpose: Used in hospital, banking and booking systems for timestamps.
Example: Printing today date on a bill receipt.
import datetime today = datetime.date.today() print(today) print(today.year)
Task: Print current date, time and year separately using datetime.

17. Random Module

Meaning: Generating unpredictable numbers and choices.
Definition: random.randint(a,b) gives integer, random.choice(list) picks random item, random.random() gives 0-1 float.
Purpose: Used for OTP generation, dice games, lottery systems.
Example: Generating 6-digit OTP for login.
import random otp = random.randint(100000, 999999) print(otp)
Task: Generate a random OTP and a random choice from a list of 5 students.

18. Math Module

Meaning: Built-in library for mathematical operations.
Definition: Provides sqrt(), ceil(), floor(), pow(), pi, factorial() and more.
Purpose: Performs accurate scientific and billing calculations.
Example: Calculating square root and power for interest logic.
import math print(math.ceil(4.2)) print(math.factorial(5))
Task: Take radius as input and calculate circle area using math.pi.

19. Loops - For Loop

Meaning: Repeating code for each item in a sequence.
Definition: for variable in range/list/string: executes block. range(5) gives 0 to 4.
Purpose: Automates repetitive tasks like printing tables or processing lists.
Example: Printing multiplication table of 5.
for i in range(1, 6): print(i * 5)
Task: Use for loop to print even numbers from 1 to 20.

20. Loops - While Loop, Break & Continue

Meaning: Repeating code while a condition stays True.
Definition: while condition: runs until False. break exits loop fully. continue skips current iteration.
Purpose: Used when number of repetitions is unknown like password retry.
Example: Asking password until correct with max 3 tries.
i = 1 while i <= 5: if i == 3: i += 1 continue print(i) i += 1

21. PIP (Python Package Installer)

Meaning: Official tool to install external Python libraries.
Definition: pip install package-name downloads from PyPI. pip list shows installed packages, pip uninstall removes.
Purpose: Connects Python with MySQL, Django and thousands of libraries.
Example: pip install mysql-connector-python for database connection.
pip install requests pip list

📅 Lecture 05 | Module 05: OOPS, Map & Filter Day 5

22. Python OOPS (Class, Object, Inheritance)

Meaning: Programming style that organizes code around real-world objects.
Definition: Class is blueprint, Object is real instance. __init__ is constructor. Pillars: Inheritance (reuse parent), Encapsulation (hide data), Polymorphism (same name different work).
Purpose: Builds scalable banking, hospital and management systems.
Example: BankAccount class with deposit and withdraw methods used for many customers.
class Student: def __init__(self, name, marks): self.name = name self.marks = marks def result(self): return "Pass" if self.marks >= 40 else "Fail" s1 = Student("Aarav", 85) print(s1.result())
Task: Create BankAccount class with deposit() and withdraw() and test with 2 objects.

23. map() Function

Meaning: Applies a function to every item in a list and returns new values.
Definition: map(function, iterable). Returns map object, so wrap with list(). Often used with lambda.
Purpose: Transforms data without writing loops, like doubling prices.
Example: Converting list of strings to integers.
nums = [1, 2, 3, 4] double = list(map(lambda x: x * 2, nums)) print(double)
Task: Use map() to convert temperatures list from Celsius to Fahrenheit.

24. filter() Function

Meaning: Keeps only items that pass a condition.
Definition: filter(function, iterable). Function must return True/False. True items are kept.
Purpose: Filters data like adult users, passed students, in-stock products.
Example: Keeping only even numbers from a list.
nums = [1, 2, 3, 4, 5, 6] evens = list(filter(lambda x: x % 2 == 0, nums)) print(evens)
Task: Use filter() to keep only names with length greater than 4 from a list.
